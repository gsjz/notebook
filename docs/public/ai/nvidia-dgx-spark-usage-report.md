# NVIDIA DGX Spark 使用报告

## 背景

25 年刚入门机器学习的时候，我尝试在自己的笔记本上做实验。当时我还是纯 Windows 用户，所以就尝试在 WSL 上跑实验。但是训练时 WSL 进程很容易被 Windows 杀掉（我猜想是内存超限导致的问题）。随后我做了两个不同方向的尝试，一个是在 AutoDL 上租服务器，然而它那网速实在感人，基本无法正常使用；另一个方向是在笔记本上装一个 Ubuntu，但我发现它经常性地卡死机（我猜想是桌面端 Ubuntu 的显卡驱动导致的）。总的来说就是很难受。

26 年四月份左右，随着龙虾热，我租了一年的优惠腾讯云服务器（200 左右一年），但是很快我发现龙虾是一个不成熟的泡沫，于是转而用来伺服一些自己的项目。刚开始觉得还是挺香的，毕竟有了一个公网 IP，但我发现它网速、储存方面都还是比较乞丐的，升级或者续费起来的话也就不便宜了，并且还有一个严肃的问题就是我的个人设备 IP 经常变化，导致防火墙非常难设置。五月份左右，我买了一台 1k 左右的小主机（CPU 应该是 N100），装了 Ubuntu Server 系统，用来伺服我的 [Linkual Log](https://github.com/gsjz/linkualog) 和 [Private Notebook](https://github.com/gsjz/notebook)，还有 [LLM API 个人聚合站](/public/ai/llm-api-gateway)；并用 Tailscale 来满足我一人的“伪”公网需求。体验上，它比腾讯云已经好用很多了，并且长远来看还是蛮实惠了。

26 年 8 月，由于研究 LLM 相关的领域，我需要在本地跑 20B 左右规模的 LLM，进行一些探索性的实验。我之前觉得我的 4080 Laptop 还是很牛比的，然而由于老生常谈的显存瓶颈，它在没那么大的大模型面前仍然捉襟见肘，基本只能跑 0.6B 的超小模型。于是我考虑从家里爆金币买两张专业显卡（毕竟从现在到研究生毕业还有五年，自己有卡的话会方便很多，长期来看对我的学业助力还是蛮大的）。结果阴差阳错地碰上 PRO 6000 价格翻了一倍！！！并且 RAM 价格早涨上天了，估计得等我本科毕业泡沫才能破掉。冷静了一下觉得还是不要抄顶当冤种了。

## 入坑

最开始在淘宝刷到三万多的“AI 小主机”，我会嘲笑说为什么有傻呗会买这智商税玩意。然而时过境迁，我发现这个东西放在现在居然还挺有性价比的？？？一张显存 96G 的 PRO 6000 现在涨到 12 万了，这个统一内存 128G 的小主机一年降了 5000 块钱，只需要 3 万。按照现在普通 RAM 的市场价来说，128G 本身就要一万多了，并且这个 RAM 还是可以当显存用的。虽然算力确实还不如我的笔记本。。。但起码解决了本地部署 LLM 会 OOM 的瓶颈。简单对比了一下，我选择了技嘉的 4TB SSD 版本。
