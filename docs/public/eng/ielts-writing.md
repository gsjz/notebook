# IELTS Writing Notes

这篇笔记把 IELTS Academic Writing 的 Task 1 和 Task 2 常见题型合在一起，方便写作前快速判断题型、选结构、检查文章是否完整。

!!! abstract "使用方式"
    先判断题型，再套对应的段落功能。Task 1 重点是选择和报告图表信息；Task 2 重点是回应题目要求、发展论证并保持立场一致。

## Overall Principles

| Task | Minimum length | Core job | Main risk |
| --- | --- | --- | --- |
| Task 1 | 150 words | report visual information | 写观点、解释原因、机械报数 |
| Task 2 | 250 words | answer an argument question | 立场不清、漏答问题、观点没有展开 |

### Shared Writing Rules

- Read the command words before writing.
- Keep the style formal or neutral.
- Write an overview in Task 1.
- State a clear answer or position in Task 2 when the prompt requires it.
- Use examples as support, not as stories.
- Avoid invented statistics, unsupported reasons or memorised full essays.

!!! warning "Task 1 和 Task 2 的分界"
    Task 1 描述题目给出的信息；Task 2 回答观点、政策、问题或趋势。Task 1 不需要解释社会原因，Task 2 不能只复述现象。

## Task 1: Academic Visual Information

Task 1 常见材料包括 chart, table, process diagram, map and plan。不同题型的细节不同，但基本结构稳定。

| Paragraph | Function | What to write |
| --- | --- | --- |
| Introduction | 改写题目 | 图表展示什么、比较什么、时间或地点是什么 |
| Overview | 总览 | 最大趋势、主要变化、流程类型或最明显差异 |
| Body 1 | 第一组信息 | 按趋势、区域、阶段或对象组织细节 |
| Body 2 | 第二组信息 | 补充另一组细节、对比项或剩余阶段 |

!!! tip "Overview 的任务"
    Overview 要从整体看图，写最重要的变化或差异。数字、每一步细节和小项目通常放在 body paragraphs。

### Task 1 Checklist

1. Did I identify the visual type correctly?
2. Did I paraphrase the task?
3. Did I include a clear overview?
4. Did I group information logically?
5. Did I avoid unsupported explanations and opinions?

## Task 1: Chart Analysis

Chart analysis 包括 line graph, bar chart, pie chart, table 和 mixed charts。核心动作是比较数据、描述趋势、选择关键数字。

### Introduction and Overview

Useful paraphrase patterns:

| Meaning | English |
| --- | --- |
| 这张图展示变化 | The chart illustrates changes in... |
| 这张图比较对象 | The chart compares... |
| 这张表给出数据 | The table presents data on... |
| 主题是比例 | the proportion / percentage of... |
| 主题是数量 | the number of... |
| 主题是花费 | the amount of money spent on... |
| 时间是 2000 到 2020 | between 2000 and 2020 |
| 地点是某个国家或城市 | in one country / in a city |

Useful overview patterns:

| Main feature | English |
| --- | --- |
| A 一直最高 | Overall, A remained the highest category throughout the period. |
| A 上升，B 下降 | Overall, A increased, while B declined. |
| A 增长最快 | A showed the fastest growth. |
| A 后来反超 B | A overtook B by the end of the period. |
| A 和 B 走势相似 | A and B followed similar trends. |
| 差距变大 | The gap between A and B widened over time. |
| 差距变小 | The difference between A and B narrowed by the end of the period. |
| 从 A 转向 B | There was a clear shift from A to B. |

Example:

> The line graph illustrates changes in the proportion of city residents using cars, buses and bicycles between 2000 and 2020. Overall, car use remained the most common form of transport, although it declined slightly, while cycling showed the fastest growth and overtook bus use by the end of the period.

### Grouping Data

第二、三段不要按图上顺序逐个报数。先分组，再写每组里的关键数据。

| Grouping method | Suitable charts | Body 1 / Body 2 |
| --- | --- | --- |
| by trend | line graph, time-based bar chart | rising / falling or stable |
| by value | bar chart, pie chart, table | main categories / minor categories |
| by time | charts with clear periods | earlier period / later period |
| by object | gender, country, age group | group A / group B |
| by theme | mixed charts, tables | population / development indicators |

!!! tip "A good group has a reason"
    更好的分组应该能说成一句话，例如“这几个都在上升”“这几个占比最高”“这两个体现相反趋势”。

### Body Language

```text
main feature of this group + key numbers + comparison or change
```

| Meaning | English |
| --- | --- |
| 先看 A 这一组 | Looking first at A,... |
| 在 A 方面 | In terms of A,... |
| A 是最大的 | A was the largest category, at... |
| A 从多少涨到多少 | A rose from... to... |
| A 从多少降到多少 | A fell from... to... |
| A 保持稳定 | A remained stable at around... |
| A 达到峰值 | A peaked at... in... |
| A 大约是 B 的两倍 | A was roughly twice as high as B. |
| A 和 B 差不多 | A and B were similar, at... and... respectively. |
| A 和 B 合起来占多少 | A and B together accounted for... |
| 到最后 A 超过了 B | By the end of the period, A had overtaken B. |

!!! warning "Percentage vs percentage points"
    从 20% 到 30% 是 an increase of 10 percentage points。`Percent` 更常用于相对变化，精确描述两个百分比之间的直接差值时，用 `percentage points` 更清楚。

### Chart Sample Answer

Prompt idea:

> The line graph shows the percentage of people using three forms of transport in a city from 2000 to 2020.

!!! example "Sample answer"
    The line graph illustrates changes in the proportion of city residents using cars, buses and bicycles between 2000 and 2020. Overall, car use remained the most common form of transport, although it declined slightly, while cycling showed the fastest growth and overtook bus use by the end of the period.

    Looking first at the two declining categories, cars were used by 55% of residents in 2000, far above the figures for buses and bicycles. Car use then rose marginally to 60% in 2010 before dropping back to 50% by 2020. Bus use fell more steadily, from 30% to 20% over the same period.

    Bicycle use showed the clearest increase. It tripled from 10% in 2000 to 30% in 2020, which meant that it became more common than bus use by the end of the period.

Common mistakes:

| Mistake | Better approach |
| --- | --- |
| 只换一个 `shows` 就结束第一段 | 第一段还要写 overall message |
| overview 里塞太多数字 | 把数字留给 body paragraphs |
| 按图表顺序逐个报数 | 先按趋势、数值或对象分组 |
| 写原因或观点 | 只描述图表给出的信息 |
| 忘记单位 | 写清 percentage, number, dollars, tonnes 等 |

## Task 1: Process Diagram

Process diagram 可能展示制造、回收、设备运行或自然循环。它的重点不是比较数据，而是解释 sequence。

### Reading the Diagram

Before writing, mark these features:

- input: raw material, information, energy, water, waste
- output: final product, result, waste, reusable material
- first stage and final stage
- number of main stages
- arrows and direction
- branches, loops or repeated cycles
- human action vs natural process
- machines, containers, locations or conditions

!!! warning "Do not invent missing information"
    如果图里只显示 `heated`，不要自行写温度；如果图里只显示 `stored`，不要自行写储存时长。

### Structure and Overview

| Paragraph | Function | What to write |
| --- | --- | --- |
| Introduction | 改写题目 | 这个流程展示什么被制造、处理、循环或运作 |
| Overview | 总览 | 起点、终点、阶段数量、是否循环、是否分支 |
| Body 1 | 前半段 | 从第一步写到中间关键节点 |
| Body 2 | 后半段 | 从中间节点写到最终结果，补充分支或循环 |

Useful overview patterns:

- Overall, the process consists of X main stages, beginning with A and ending with B.
- Overall, this is a linear process in which A is converted into B through several steps.
- Overall, the process is cyclical, as the final stage leads back to the starting point.
- Overall, there are two main phases: preparation and final production.
- Overall, the process relies on both manual sorting and mechanical treatment.

### Sequencing Language

| Function | Language |
| --- | --- |
| basic sequence | initially, next, after that, then, subsequently, finally |
| after / before | after being cleaned, before it is packaged, once the mixture has cooled |
| purpose | in order to, so that, to remove impurities, to produce a smoother liquid |
| cause / result | as a result, this produces, this allows, this causes, this leads to |

Examples:

> Initially, the fruit is washed and sorted.

> After being crushed, the fruit is pressed to extract the juice.

> The mixture is heated, which causes the water to evaporate.

### Passive Voice

Manufacturing and recycling processes usually use passive voice because the actor is often unimportant.

| Active | Passive |
| --- | --- |
| Workers wash the fruit. | The fruit is washed. |
| Machines crush the bottles. | The bottles are crushed. |
| The factory heats the mixture. | The mixture is heated. |
| Staff pack the final product. | The final product is packed. |

Useful pattern:

```text
subject + is/are + past participle + sequence/purpose detail
```

!!! warning "Passive voice 不要全篇机械重复"
    可以用 passive voice 作为主干，但要穿插 `after`, `before`, `which`, `where` 等结构，否则文章会变成一串短句。

### Process Sample Answer

Prompt idea:

> The diagram shows how used glass bottles are recycled and made ready for reuse.

!!! example "Sample answer"
    The diagram illustrates the process by which used glass bottles are recycled and prepared for reuse.

    Overall, this is a linear process with six main stages, beginning with the collection of empty bottles and ending with the delivery of refilled bottles to shops. The process includes both sorting and cleaning before the bottles can be used again.

    At the first stage, used glass bottles are collected from recycling points and transported to a cleaning plant. Once they arrive, they are washed thoroughly to remove any remaining liquid or dirt. The bottles are then sorted according to colour, such as clear, green and brown glass.

    After sorting, damaged bottles are removed from the production line, while suitable bottles continue to the next stage. These bottles are sterilised before being filled with new drinks. Finally, they are labelled, packed into boxes and delivered to shops, where they are ready to be sold again.

Common mistakes:

| Mistake | Better approach |
| --- | --- |
| describing a process like a chart | focus on stages, not trends |
| forgetting the overview | summarize start, end and process type |
| writing only short sentences | connect steps with `after`, `before`, `once`, `which` |
| using personal opinion | describe only the diagram |
| inventing reasons or numbers | use only given information |

## Task 1: Map and Plan

Maps and plans ask you to describe changes in a place, differences between sites, or proposed redevelopment.

!!! note "Map/plan 的核心"
    地图题不靠数字取胜，而靠方位、变化和分组。总览里优先写最大变化：扩建、改造、功能转移、绿地减少、交通改善等。

### Common Map Types

| Type | What to compare |
| --- | --- |
| past and present map | what was added, removed, replaced or unchanged |
| present and future plan | proposed changes and new facilities |
| two locations | advantages and disadvantages of each site |
| building plan | rooms, entrances, facilities and internal layout |
| town/campus plan | roads, services, residential areas, green space |

### Location Language

| Function | Language |
| --- | --- |
| directions | in the north, to the south of, on the eastern side of |
| precise position | in the north-western corner, in the centre of, along the river |
| relation | near the entrance, opposite the station, next to the car park |
| replacement | was replaced by, was converted into, gave way to |
| addition | was built, was added, was introduced, was constructed |
| removal | was removed, was demolished, was cleared |
| size change | was expanded, was extended, was reduced in size |
| unchanged | remained unchanged, stayed in the same location |

Examples:

> A new car park was built in the north-eastern corner of the site.

> The old playground, which was located to the west of the school, was replaced by a sports centre.

### Grouping the Body Paragraphs

| Grouping method | Body 1 | Body 2 |
| --- | --- | --- |
| by direction | north and centre | south and east |
| by change type | new or expanded features | removed, replaced or unchanged features |
| by function | transport and public services | housing and leisure |
| by time | earlier layout | later layout |
| by site comparison | site A | site B |

!!! tip "先找不变量"
    保留下来的道路、河流、入口或中心建筑可以作为参照物，让位置描述更清楚。

### Map Sample Answer

Prompt idea:

> The maps show a town centre in 2000 and after redevelopment in 2025.

!!! example "Sample answer"
    The maps compare the layout of a town centre in 2000 with its layout after redevelopment in 2025.

    Overall, the town centre became more commercial and transport-oriented, although the market square and the main road remained in the same positions. The most noticeable changes were the construction of a shopping mall and a new bus station.

    In 2000, the central feature of the town was a market square, with a park to the north and a row of small shops on the eastern side. By 2025, the market square had remained unchanged, but the shops to the east had been demolished and replaced by a large shopping mall. The northern park was also reduced in size to make space for a bus station near the main road.

    Changes in the southern part of the town were mainly related to transport. The original car park, which was located south of the market square, was expanded considerably. Meanwhile, the main road continued to run from west to east across the town centre, providing access to both the new bus station and the enlarged car park.

Common mistakes:

| Mistake | Better approach |
| --- | --- |
| listing every object separately | group by area or function |
| forgetting unchanged features | mention them when they clarify the comparison |
| using weak location language | use direction and reference points |
| explaining why changes happened | describe only what the maps show |
| confusing left/right with east/west | prefer map directions when available |

!!! danger "No unsupported reasons"
    `The park was reduced to make space for a bus station` is acceptable if the map shows the bus station occupying that area. `The park was reduced because the town needed more public transport` adds a reason that the map does not prove.

## Task 2: Essay Writing

Task 2 的核心是看清 prompt 在问什么。常见题型包括 opinion essay, discussion essay, advantages and disadvantages, problem and solution, two-part question。

### General Task 2 Structure

| Paragraph | Function | What to write |
| --- | --- | --- |
| Introduction | 改写题目 + 回答方向 | paraphrase + clear thesis |
| Body 1 | 主体观点 1 | topic sentence + explanation + example |
| Body 2 | 主体观点 2 | topic sentence + explanation + example |
| Conclusion | 回答题目 | summarize without adding new ideas |

### Body Paragraph Pattern

```text
topic sentence + explanation + example/detail + link back to question
```

Useful language:

| Function | Language |
| --- | --- |
| giving an opinion | I believe that..., In my view,..., I would argue that... |
| giving reasons | The main reason is that..., A further reason is that... |
| giving examples | For example,..., For instance,..., This can be seen in... |
| showing limits | However, this does not mean that..., This may be true in some cases, but... |
| evaluating | This is more significant because..., These drawbacks can be reduced if... |

!!! danger "Do not memorise a full essay"
    IELTS.org warns against formulaic learned responses because they may not address the task. Memorise flexible structures and useful language, not whole essays.

## Task 2: Opinion Essay

### Common Prompt Wording

| Prompt | What it asks |
| --- | --- |
| To what extent do you agree or disagree? | 你同意到什么程度 |
| Do you agree or disagree? | 你是否同意 |
| What is your opinion? | 你的观点是什么 |
| Do you think this is a positive or negative development? | 判断整体倾向 |
| Should governments/individuals do this? | 对政策或行为表态 |

### Position Types

| Position | When to use |
| --- | --- |
| completely agree | 题目观点基本合理，反方较弱 |
| completely disagree | 题目观点明显片面或不成立 |
| partly agree | 题目有合理部分，但需要限制条件 |
| positive development | 好处明显大于问题 |
| negative development | 问题明显大于好处 |

Useful thesis patterns:

- I completely agree with this view because...
- I largely agree with this statement, although...
- I disagree with this view, as...
- In my view, this is a positive development overall because...
- I believe that this policy should be adopted, provided that...

!!! tip "立场要早出现"
    Task 2 要让 position 清楚。最稳妥的做法是在 introduction 最后一句直接写出自己的答案。

### Opinion Essay Sample Answer

Prompt idea:

> Some people believe that university students should study only subjects that will be useful for their future careers. To what extent do you agree or disagree?

!!! example "Sample answer"
    Some people argue that university students should focus only on subjects with clear career value. I partly agree with this view because employment is an important purpose of higher education, but I do not think universities should remove subjects that develop broader thinking.

    Career-related study is important because many students invest significant time and money in university education. If their courses teach practical knowledge and professional skills, graduates are more likely to find suitable work and adapt quickly to the workplace. For example, engineering students need technical training, laboratory experience and problem-solving practice that directly prepare them for their future jobs.

    However, studying only career-focused subjects would make university education too narrow. Courses in history, philosophy or communication can help students think critically, understand society and express complex ideas clearly. These abilities may not be linked to one specific job, but they are valuable in many professions. A manager, for instance, needs judgement and communication skills as well as technical knowledge.

    In conclusion, I agree that universities should provide strong career preparation, but I do not believe students should study only career-related subjects. A balanced education is more useful because it combines professional skills with broader intellectual development.

Common mistakes:

| Mistake | Better approach |
| --- | --- |
| no clear position | state the answer in the introduction and conclusion |
| changing position halfway | keep the same judgement throughout |
| memorised opening | paraphrase the specific prompt |
| too many undeveloped ideas | develop two main reasons well |
| only discussing both sides | include your own judgement |

## Task 2: Discussion Essay

Discussion essays ask you to explain two viewpoints. Many prompts also ask for your own opinion.

!!! note "Discussion essay 的核心"
    `Discuss both views and give your own opinion` 有三个任务：view A、view B、your opinion。漏掉任何一个都会影响 task response。

### Structure

| Paragraph | Function | What to write |
| --- | --- | --- |
| Introduction | 改写题目 + 立场 | mention both views and your opinion |
| Body 1 | View A | explain why some people hold view A |
| Body 2 | View B + your view | explain view B and show your judgement |
| Conclusion | 回答问题 | summarize both views and repeat your opinion |

Useful patterns:

- While some people believe that A, others argue that B. In my view,...
- There is debate over whether A or B is more important. I believe that...
- This essay will discuss both views before explaining why I support...
- Although the first view has some merit, I believe...

!!! warning "Discuss 不等于 list"
    不要把两个观点写成两个清单。每个观点都要解释为什么有人会这样想，并用例子或细节展开。

### Discussion Essay Sample Answer

Prompt idea:

> Some people think that students should work in groups at school, while others believe that they should study independently. Discuss both views and give your own opinion.

!!! example "Sample answer"
    Some people believe that group work is an essential part of school education, whereas others think students learn better when they study alone. In my view, both methods are useful, but group work should be used regularly because it develops skills that individual study cannot easily provide.

    Supporters of independent study argue that students need quiet time to understand difficult material at their own pace. This is especially true for subjects such as mathematics or writing, where learners often need to practise, make mistakes and correct their own thinking. Independent study can also help students become more responsible because they cannot rely on classmates to complete the task for them.

    However, group work has important advantages. When students discuss a problem together, they are exposed to different explanations and can learn how to communicate their ideas clearly. This is useful not only for academic learning but also for future workplaces, where cooperation is often required. For example, a science project may require students to divide roles, compare evidence and agree on a final conclusion.

    In conclusion, independent study is valuable for concentration and personal responsibility, but I believe group work should have a regular place in schools. It builds communication and cooperation skills that are difficult to develop through individual study alone.

Common mistakes:

| Mistake | Better approach |
| --- | --- |
| discussing only the side you agree with | explain both views first |
| no personal opinion | state your judgement if the prompt asks for it |
| attacking one view too strongly | explain why people may reasonably hold it |
| using memorised phrases mechanically | adapt structure to the exact prompt |

## Task 2: Advantages and Disadvantages

Advantages/disadvantages prompts ask you to evaluate the good and bad sides of a situation, policy or trend.

!!! note "先看题目有没有 judgement"
    `What are the advantages and disadvantages?` 可以平衡讨论。`Do the advantages outweigh the disadvantages?` 必须判断哪一边更强。

### Two Main Structures

| Prompt type | Paragraph structure |
| --- | --- |
| no strong opinion required | Introduction + advantages + disadvantages + summary |
| outweigh / positive-negative | Introduction with judgement + weaker side + stronger side + judgement |

Useful thesis patterns:

- This development has both benefits and drawbacks.
- Although this trend has some disadvantages, I believe its advantages are greater.
- In my view, the disadvantages outweigh the advantages because...
- Overall, I consider this a positive development despite some risks.

!!! warning "不要只数数量"
    `outweigh` 不是简单数出 3 个好处和 2 个坏处。重点是说明哪一边影响更大、更长期、更普遍或更难解决。

### Advantages and Disadvantages Sample Answer

Prompt idea:

> More people are choosing to work from home instead of travelling to an office. Do the advantages of this development outweigh the disadvantages?

!!! example "Sample answer"
    Working from home has become increasingly common as digital communication tools have improved. Although this trend can create some problems for teamwork, I believe its advantages outweigh its disadvantages because it saves time and gives workers greater flexibility.

    The main disadvantage is that remote work can make communication less efficient. In an office, employees can ask quick questions, read body language and solve small problems immediately. By contrast, online communication may lead to delays or misunderstanding, especially when a project requires close cooperation. New employees may also find it harder to learn from experienced colleagues if they rarely meet them in person.

    However, the benefits are more significant for many workers. The most obvious advantage is that people no longer need to spend hours commuting, which gives them more time for rest, family or focused work. Remote work can also make employment more inclusive because people who live far from major cities can apply for jobs that were previously unavailable to them. These benefits affect both employees and employers, as companies can recruit from a larger talent pool.

    In conclusion, working from home can weaken some forms of communication, but I believe the advantages are greater overall. The time saved and the increased flexibility make remote work a positive development when it is managed carefully.

Common mistakes:

| Mistake | Better approach |
| --- | --- |
| writing only advantages | include disadvantages if the prompt requires them |
| no final judgement in `outweigh` questions | say which side is stronger |
| listing many points briefly | develop two or three important points |
| treating all effects as equal | explain importance, scale or seriousness |
| adding fake statistics | use general examples from knowledge or experience |

## Task 2: Problem and Solution

Problem/solution essays ask you to analyse a problem and explain how it can be addressed. Some prompts ask for causes and solutions; others ask for problems and solutions, or causes and effects.

!!! note "Problem/solution 的核心"
    要写清楚问题是什么、为什么发生、谁能解决、解决方法如何起作用。

### Prompt Types

| Prompt | What it asks |
| --- | --- |
| What are the causes of this problem and what solutions can you suggest? | 原因 + 解决办法 |
| What problems does this cause and how can they be solved? | 问题/影响 + 解决办法 |
| Why has this happened? What can be done to address it? | 原因 + 应对 |
| What are the effects of this trend? What measures should be taken? | 影响 + 措施 |

### Development Pattern

```text
cause/problem + explanation + example + consequence
solution + actor + how it works + expected result
```

Useful language:

| Function | Language |
| --- | --- |
| causes | One major cause is..., This happens because..., A further reason is... |
| problems/effects | This leads to..., As a consequence,..., The most serious problem is... |
| solutions | Governments should..., One effective measure would be to..., This could be addressed by... |
| linking | To address this,..., This measure would reduce the problem by..., As a result,... |

!!! warning "Cause, problem, effect 不要混用"
    `Traffic congestion is caused by too many private cars` 是 cause。`Long commuting times` 是 problem/effect。`Improving public transport` 是 solution。

### Problem and Solution Sample Answer

Prompt idea:

> In many cities, young people find it difficult to buy their first home. What problems does this cause, and what solutions can you suggest?

!!! example "Sample answer"
    In many urban areas, buying a first home has become increasingly difficult for young adults. This creates problems for personal independence and family planning, but the situation could be improved through better housing policy and support for first-time buyers.

    One major problem is that young people may have to delay important life decisions. If they cannot afford a home, they may continue living with parents or spend a large proportion of their income on rent. This can make it harder for them to save money, start a family or feel settled in the city where they work. High housing costs can also increase inequality between people who receive family support and those who do not.

    Governments can address this issue by increasing the supply of affordable housing and limiting speculative investment in residential property. For example, cities could require new developments to include a proportion of lower-cost homes for first-time buyers. Banks could also offer carefully regulated mortgage support to young workers with stable incomes, so that assistance goes to people who can realistically repay their loans.

    In conclusion, the difficulty of buying a first home can delay independence and widen inequality among young adults. The best solutions are to expand affordable housing and provide targeted financial support for genuine first-time buyers.

Common mistakes:

| Mistake | Better approach |
| --- | --- |
| only describing the topic | identify concrete causes/problems |
| vague solutions | explain who acts and how it helps |
| solution does not match problem | pair each solution with a cause/problem |
| too many problems | develop one or two well |
| turning it into an opinion essay | keep focus on cause/problem and solution |

!!! danger "No magic solutions"
    `The government should solve this problem` is too vague. A solution needs an action, an actor and a reason it would reduce the problem.

## Task 2: Two-Part Question

Two-part questions ask you to answer two related questions after one topic statement.

!!! note "Two-part 的核心"
    两问都要答。最稳妥的结构是 Body 1 回答第一问，Body 2 回答第二问。

### Common Prompt Wording

| Prompt | What it asks |
| --- | --- |
| Why is this happening? Is this a positive or negative development? | 原因 + 判断 |
| What are the reasons for this? What effects does it have? | 原因 + 影响 |
| Do you think this is a good idea? What problems might it cause? | 观点 + 问题 |
| Why do some people prefer this? Should governments encourage it? | 原因 + 政策立场 |

### Structure

| Paragraph | Function | What to write |
| --- | --- | --- |
| Introduction | 改写题目 + 简短答案 | mention both parts |
| Body 1 | Answer question 1 | reason/explanation/example |
| Body 2 | Answer question 2 | answer/evaluation/example |
| Conclusion | 总结两问 | repeat both answers briefly |

Useful language:

| Function | Language |
| --- | --- |
| answering why | This is mainly because..., One reason is that... |
| answering effects | This has several effects on..., One important consequence is... |
| answering judgement | I believe this is largely positive because..., In my view, the trend is negative overall. |
| moving between parts | Turning to the second question,..., As for its effects,... |

!!! warning "不要写成普通 opinion essay"
    如果第一问是 `Why is this happening?`，不能直接从头到尾只写 `I agree`。先解释原因，再评价。

### Two-Part Sample Answer

Prompt idea:

> In many countries, people are spending less time cooking at home. Why is this happening? Is this a positive or negative development?

!!! example "Sample answer"
    In many countries, home cooking has become less common than it was in the past. This essay will argue that the main reasons are busier lifestyles and easier access to prepared food, and that the trend is negative overall despite some convenience.

    One reason for this change is that many people have less time and energy to cook. Long working hours and lengthy commutes mean that preparing a meal from raw ingredients can feel unrealistic on a normal weekday. In addition, food delivery apps and ready-made meals have made alternatives to home cooking cheaper and more convenient. As a result, people may choose restaurant food even when they know that cooking at home would be healthier.

    In my view, this is a negative development overall. Although prepared food saves time, it can weaken people's ability to manage their diet and household spending. Meals bought from restaurants or delivery platforms are often higher in salt, fat or sugar, and they are usually more expensive than simple home-cooked meals. If this becomes a daily habit, it may damage both public health and personal finances.

    In conclusion, people are cooking less mainly because modern life is busy and convenient food is widely available. However, I believe this trend is mostly negative because it can reduce healthy habits and increase everyday costs.

Common mistakes:

| Mistake | Better approach |
| --- | --- |
| answering only one question | allocate one body paragraph to each question |
| weak introduction | mention both parts in the thesis |
| no final answer | summarize both answers in the conclusion |
| mixing too many ideas | keep each paragraph tied to its question |
| giving examples unrelated to the question | examples should prove the answer to that part |

## Final Checklist

### Task 1

1. Did I write at least 150 words?
2. Did I include a separate overview?
3. Did I select main features instead of listing everything?
4. Did I use accurate numbers, units, directions or stages?
5. Did I avoid opinions and unsupported explanations?

### Task 2

1. Did I write at least 250 words?
2. Did I answer every part of the prompt?
3. Did the introduction show my answer or essay direction?
4. Did each body paragraph develop one main idea?
5. Did the conclusion repeat the same answer without adding a new argument?

!!! success "Reliable formulas"
    Task 1: `Paraphrase + overview + grouped details + grouped details`.

    Opinion essay: `Clear position + two developed reasons + consistent conclusion`.

    Discussion essay: `View A + View B + my judgement`.

    Outweigh essay: `Weaker side + stronger side + clear final judgement`.

    Problem/solution essay: `Problem or cause + matching solution + how the solution works`.

    Two-part question: `One prompt + two questions + two body answers`.
