# CET-6 Translation Notes

## Topic Map

CET-6 翻译是段落汉译英，官方题型说明为 `段落翻译`，分值比例为 15%，考试时间为 30 分钟。题材通常围绕中国文化、社会发展、科技工程、地理区域和民生治理。

| 方向 | 近年常见主题 | 备考重点 |
| --- | --- | --- |
| 地理与区域 | 省份、高原、湾区、城市群 | 位置、面积、资源、发展目标 |
| 科技与工程 | 北斗、航天、港口、水利、桥梁 | 建设时间、技术突破、应用领域 |
| 传统文化 | 婚礼、竹、扇子、传统美德 | 历史渊源、象征意义、现代传承 |
| 社会民生 | 养老、公共设施、宜居城市 | 政策措施、服务体系、生活改善 |
| 国家发展 | 改革开放、创新、现代化 | 成就、贡献、未来目标 |

| 高频模式 | 代表题目 | 写法重点 |
| --- | --- | --- |
| 介绍地方 | 海南、云南、青海、三大高原、粤港澳大湾区 | 位置 + 特点 + 发展价值 |
| 介绍工程 | 三座桥、南水北调、北斗、洋山港 | 建设背景 + 技术特点 + 社会作用 |
| 介绍文化物品 | 扇子、竹子、印章、春联 | 实用功能 + 象征意义 + 传承 |
| 介绍社会政策 | 老龄化、养老服务、公共设施、宜居城市 | 问题背景 + 政府措施 + 改善效果 |
| 介绍历史人物 | 张骞、郑和、徐霞客 | 身份定位 + 主要行动 + 历史影响 |
