# 总线

总线规定部件之间的信息传送方式。传统共享总线通过分时使用公共线路降低连接成本；现代 PCIe 等接口则使用点对点串行链路与交换结构。分类、定时和带宽公式都需要先确定所用模型，不能把共享并行总线的全部性质直接移植到现代接口。

## 基本概念

传统共享总线是一组可供多个部件分时共享的公共信息传输线路。它解决的是部件互连问题：设备数量增加后，如果所有部件都用专线相连，连线和接口会迅速复杂起来；把多个部件接到公共线路上，扩展和维护都更方便。

这种共享线路有两个基本特征：

- **分时性**：同一组共享信号线在同一时刻通常只允许一个发送方驱动。
- **共享性**：多个部件可以挂接在同一条总线上，也可以同时接收总线上的信息。

这里要把发送和接收分开。发送方会驱动总线电平，多个发送方同时驱动同一组线会造成冲突；接收方只是读取线路电平，多个接收方同时监听一般不会破坏信号。

从物理直觉看，传统共享总线像一组大家都接得上的公共导线。某个设备获得控制权后，在线路上驱动高低电平；其他挂接设备在物理上也能感知这些变化。它们是否处理这次传输，取决于地址、控制信号和协议规则。

| 问题 | 常见实现 |
| --- | --- |
| 谁能发送 | 协议指定的当前发送方；读事务的数据阶段通常由从设备返回数据 |
| 发给谁 | 地址线、端口地址、设备地址或协议标识 |
| 传什么 | 数据线或数据字段 |
| 怎样配合 | 控制线、时钟、握手、确认信号 |

传统三态总线中，暂时不发送的设备会让输出端处于高阻态 `High-Z`，相当于只监听、不驱动。现代高速点对点总线的电气结构已经不同，但访问前仍要明确通信参与者、传输方向和时序规则。

总线结构的优势是减少连线、统一接口、便于扩展。代价也很直接：公共通路会成为共享资源，多主设备同时请求时需要决定谁先使用，整体并行性也可能低于专线连接。

## 总线分类

按连接层次划分，常见总线可以分成下面几类。

| 类型 | 连接对象 | 例子或说明 |
| --- | --- | --- |
| 内部总线 | CPU 芯片内部的寄存器、ALU 等 | 也叫片内总线 |
| 系统总线 | CPU、主存、I/O 接口等功能部件 | 常按信息性质分为数据、地址、控制三类 |
| I/O 总线 | 主机和内部 I/O 控制器 | PCI、AGP、PCIe 等 |
| 通信总线 | 主机与外部设备，或计算机系统之间 | RS-232、USB 等 |

内部总线和系统总线不在同一层。寄存器与 ALU 之间的数据交换属于 CPU 内部的数据通路；CPU、主存和 I/O 接口之间的信息交换才是系统总线这一层的问题。

## 数据总线、地址总线和控制总线

系统总线按传输信息的性质通常分为数据总线、地址总线和控制总线。

| 类型 | 主要作用 | 典型方向 |
| --- | --- | --- |
| 数据总线 | 传输指令、操作数、状态字、中断类型号等数据类信息 | 通常双向 |
| 地址总线 | 指出要访问的主存单元或 I/O 端口 | 通常由 CPU 或当前主设备发出 |
| 控制总线 | 传输时钟、复位、读写命令、总线请求/允许、中断请求/响应、传输确认等信号 | 由多条单向或双向控制线组成 |

这三个名称首先是按功能分的。很多教材示意图会把它们画成三组线，实际硬件里也常有独立的数据线、地址线和控制线；但也存在复用设计，例如地址/数据线复用。同一组物理引脚在事务前半段传地址，后半段传数据，当前含义由时序和控制信号决定。

判断信息走哪类总线时，不要只看中文语义里有没有“控制”味道。状态字、中断类型号、设备返回码会影响 CPU 后续流程，但它们是 CPU 读入后再解释的值，归数据总线。总线请求、总线允许、读/写命令、传输确认、时钟、复位、`Wait` 这类信号直接协调总线使用和事务时序，归控制总线。

地址总线常被说成单向，是从教材里的典型系统总线角度讲：CPU 给主存或 I/O 端口送地址。在有 DMA 或多主设备的系统里，由当前主设备送出地址。PCIe 等分组协议把地址、数据、命令放在协议字段中，不要求存在三组独立物理线；MSI 中断也可以通过内存写事务送达。

## 总线标准

常见总线标准更多作为概念识别材料出现，旧题里也常借这些缩写设干扰项。

| 标准 | 识别点 |
| --- | --- |
| ISA、EISA | 传统系统总线，并行 |
| PCI | 局部总线，并行，支持即插即用 |
| AGP | 面向图形加速的局部总线，并行 |
| PCIe | 高速串行、点对点、全双工，多通道组合 |
| RS-232 | 串行设备通信接口 |
| USB | 串行，连接外部设备，支持即插即用、热插拔、多设备连接 |
| SATA | 串行设备接口，常见于存储设备 |

`PCIe x16` 中的 `x16` 表示 $16$ 条 PCIe 通道组合。每条通道本身是高速串行链路，`x16` 不能按“$16\text{bit}$ 并行数据总线”处理。显卡插槽常见 `x16`，靠多条串行通道叠加带宽。

## 性能指标

总线性能题常围绕宽度、频率、总线周期、带宽和事务耗时。本页带宽单位采用十进制：$1\,\mathrm{MB/s}=10^6\,\mathrm{B/s}$，$1\,\mathrm{GB/s}=10^9\,\mathrm{B/s}$。

| 指标 | 含义 |
| --- | --- |
| 总线传输周期 | 完成一次完整总线事务的时间，常由多个时钟周期组成 |
| 总线时钟频率 | 总线基础时钟频率，是时钟周期的倒数 |
| 数据传送率 | 每秒数据拍数，常用 MT/s；部分教材将其称为工作频率，须核对题干定义 |
| 总线宽度 | 数据线条数，决定一次并行传输多少位 |
| 总线带宽 | 单位时间内可传输的最大数据量 |
| 总线复用 | 同一组线在不同时间传输不同类型的信息 |
| 总线寻址能力 | 由地址线位数决定 |

理论带宽按峰值能力计算：

$$
B_{\mathrm{peak}}=q\times r_d
$$

其中 $q$ 为每数据拍的字节数，$r_d$ 为每秒数据拍数，结果单位为 $\mathrm{B/s}$。如果宽度给的是位数，先换成字节数。例如 $64\text{bit}=8\text{B}$。

时钟频率和工作频率要分清。若一个时钟周期传输 $2$ 次数据，则：

$$
\text{工作频率}=\text{时钟频率}\times2
$$

若题干直接给出 $\text{MT/s}$，它已经表示每秒传输多少百万次，不要再乘一次“双沿”或“quad pumped”。例如 $1600\text{MT/s}$ 表示每秒 $1600\text{M}$ 次传输。

数据阶段的峰值带宽忽略地址、命令和等待开销。若题目要求某协议下可持续的最大有效吞吐，就必须计入每次事务不可消除的开销；不能只凭“最大”两个字决定公式。块完成时间和平均有效速率按明确的阶段、重叠能力与有效字节数计算。

事务有效速率按本次有效数据量除以本次总耗时：

$$
\text{有效速率}=\frac{\text{有效数据量}}{\text{事务总耗时}}
$$

多通道存储器总线通常把各通道带宽相加。点对点全双工链路要看题目问单向带宽还是双向合计带宽；若要求收发两个方向合计，才把两个方向相加。

## 总线结构

单总线结构把 CPU、主存和 I/O 设备都挂在同一条系统总线上。结构简单、成本低、扩展方便；问题是所有设备分时争用同一条通路，CPU 访存和 I/O 传输会互相影响。

双总线教学结构把存储通路与 I/O 通路分开，减少部分争用。I/O 如何抵达主存由桥接及主控能力决定，不能单凭总线条数判断是否支持 DMA。

一种传统三总线结构单列 DMA 通路，允许高速 I/O 直接与主存交换数据。现代 DMA 也可经共享互连或 PCIe 完成，不以专用 DMA 总线为必要条件。

南北桥结构把高速部件和低速 I/O 分层。北桥连接 CPU、主存、显卡等高速部件；南桥管理 USB、SATA、以太网等低速设备。再往后，内存控制器逐渐集成进 CPU，高速设备更多通过 PCIe 等点对点链路接入，传统共享前端总线的压力被拆散。

## 总线事务

总线事务是主设备和从设备之间完成一次完整信息交换的过程。主设备可以是 CPU、DMA 控制器；从设备可以是主存或 I/O 设备。

典型事务包含三个阶段：

1. 地址传送：主设备给出目标地址和读写类型。
2. 从设备响应：从设备译码、准备数据或准备接收。
3. 数据传送：数据真正经过总线完成交换。

非突发传输每次只传一个数据单元，通常要重复地址阶段。若题目还规定事务不流水、不重叠，则各次等待也串行累加；支持多个未完成请求的接口可以隐藏部分等待。

突发传输适合连续块数据。主设备先给出首地址，后续数据连续传送，地址由硬件自动递增。Cache 块填充、主存块读写常用突发传输提高有效带宽。

| 方式 | 地址开销 | 适合场景 |
| --- | --- | --- |
| 非突发传输 | 每个数据单元都要给地址 | 零散访问 |
| 突发传输 | 只给首地址，后续地址递增 | 连续块访问 |

## 串行与并行

并行传输用多条数据线同时传多个比特，短距离、较低频率时吞吐高，早期 PCI、内存总线都属于这一类。频率继续提高后，线间串扰、时序偏移会变得难处理。

串行传输按位传送，线路少，布线和抗干扰更容易控制。USB、SATA、PCIe 都采用高速串行链路。现代高速接口可以通过更高频率、差分传输、多通道组合取得高带宽，所以“并行线多就一定更快”这个判断不可靠。

异步串行通信常按字符帧传输。一个字符帧一般包括起始位、数据位、可选校验位和停止位。若题目问线路上每秒传多少比特，要把这些额外位一起算进去。

## 总线定时

总线定时规定主设备和从设备怎样按时间顺序配合完成传输。

| 定时方式 | 依据 | 特点 | 适用场景 |
| --- | --- | --- | --- |
| 同步定时 | 统一时钟 | 控制简单、速度快，周期固定 | 总线短、部件速度接近 |
| 异步定时 | 请求/回答握手 | 周期可变、可靠，控制复杂 | 设备速度差异大 |
| 半同步定时 | 统一时钟 + `Wait` 信号 | 可插入等待周期 | 需要兼顾慢速设备 |
| 分离式定时 | 请求阶段和应答阶段分离 | 等待期间释放总线，提高利用率 | 多主设备、高延迟从设备 |

同步方式依靠公共时钟。它不表示一次事务只占一个时钟周期；一次事务常由多个总线时钟周期组成。

异步方式靠握手信号。教材的不互锁、半互锁、全互锁主要区别在撤销请求与回答时是否继续确认：全互锁通常依次经历请求有效、回答有效、请求撤销、回答撤销。确认越完整，对预估设备响应时间的依赖越少；在相同器件和传播条件下，增加握手等待会增加开销，但不同协议的实际速度不能只按名称排序。

半同步方式仍按统一时钟工作，只是增加 `Wait` 信号。慢设备没准备好时，主设备插入等待周期；准备好后再继续传送。

分离式定时把事务拆成请求和应答。主设备发完地址和命令后先释放总线，从设备准备好数据后再申请总线返回结果。这样可以减少“总线被占着但没传数据”的时间。

## 总线仲裁

多个主设备请求同一资源时，仲裁决定授权顺序。集中式仲裁由统一仲裁器决定，分布式仲裁由各参与方协作完成；固定优先级便于满足紧急请求，但可能饿死低优先级请求，轮转则改善公平性。获得总线控制权后，数据阶段仍可能由从设备驱动，授权主体与当前数据发送方应区分。

## 概念与计算练习

以下练习依次覆盖概念、峰值带宽、事务耗时和定时。先写出单位与假设，再选择计算式；后面的变式用于检验同一知识点在条件改变后是否仍成立。

### 分时发送与同时接收

!!! question "例题 1：挂接设备的发送和接收"
    某系统中，`CPU`、主存、磁盘控制器和显示控制器都接在同一条系统总线上。某一总线周期内，`CPU` 正在向主存写入数据。下列说法正确的是哪一项？

    A. 显示控制器也可以同时向总线发送数据  
    B. 其他设备可以感知总线上的信号，但不能同时驱动数据线  
    C. 主存接收数据时会阻止其他设备监听总线信号  
    D. 多个发送方同时驱动总线可以提高并行性

    ??? success "参考答案"
        选 B。共享总线限制的是发送端；多个设备同时驱动数据线会造成冲突。接收端只读取电平变化，多个设备同时监听通常不会破坏信号。

### 系统总线的信息类别

!!! question "例题 2：中断类型号与读命令"
    在具有独立地址、数据和控制线的传统总线模型中，某 CPU 响应外部中断后，需要从中断控制器取得中断类型号；另一次访存操作中，CPU 要向主存发出读命令。前者和后者分别主要通过哪类总线传输？

    A. 地址总线、数据总线  
    B. 数据总线、控制总线  
    C. 控制总线、地址总线  
    D. 数据总线、地址总线

    ??? success "参考答案"
        选 B。中断类型号是 CPU 读入后再解释的数据类信息，走数据总线；读命令直接协调本次访存动作，走控制总线。

!!! question "例题 3：指令编码的传输类别"
    CPU 取指时，主存把某个单元中的指令编码送回 CPU。该编码在系统总线上传输时属于哪类信息？

    A. 地址信息  
    B. 数据信息  
    C. 控制信息  
    D. 时序信息

    ??? success "参考答案"
        选 B。指令编码从主存送回 CPU 时，在线路分类上属于数据总线传输的内容。进入 `IR` 后，它才按指令语义解释。

### 总线复用

!!! question "例题 4：地址/数据线复用"
    某同步总线有 $32$ 根地址/数据复用线。一次读事务开始时，这组线先传地址，随后传数据。这里体现的概念是什么？

    A. 串行传输  
    B. 并行传输  
    C. 总线复用  
    D. 总线仲裁

    ??? success "参考答案"
        选 C。同一组物理线路在不同时间传输不同类型的信息，属于总线复用。复用主要减少信号线或引脚数量。

### 常见总线标准

!!! question "例题 5：总线标准辨析"
    下列说法正确的是哪一项？

    A. `PCIe x16` 表示一次并行传输 $16\text{bit}$  
    B. `USB` 是串行总线，可用于外部设备连接  
    C. `CRT`、`RAM`、`MIPS` 都是总线标准缩写  
    D. `PCI` 和 `AGP` 主要用于设备与设备控制器之间的外部连接

    ??? success "参考答案"
        选 B。`PCIe x16` 表示 $16$ 条串行通道组合；`CRT`、`RAM`、`MIPS` 分别关联显示器、存储器和性能指标；`PCI`、`AGP` 更常归入局部总线。

### 理论带宽

!!! question "例题 6：基础带宽计算"
    某总线宽度为 $32\text{bit}$，时钟频率为 $80\text{MHz}$，每个时钟周期传送 $2$ 次数据。该总线的理论带宽是多少？

    A. $160\text{MB/s}$  
    B. $320\text{MB/s}$  
    C. $640\text{MB/s}$  
    D. $1280\text{MB/s}$

    ??? success "参考答案"
        选 C。$32\text{bit}=4\text{B}$，每秒传输次数为 $80\text{MHz}\times2=160\text{M}$ 次，所以带宽为 $4\text{B}\times160\text{M}/s=640\text{MB/s}$。

!!! question "例题 7：MT/s"
    某处理器总线宽度为 $64\text{bit}$，题干说明传输率为 $1600\text{MT/s}$。该总线理论带宽约为多少？

    A. $6.4\text{GB/s}$  
    B. $12.8\text{GB/s}$  
    C. $25.6\text{GB/s}$  
    D. $51.2\text{GB/s}$

    ??? success "参考答案"
        选 B。$1600\text{MT/s}$ 已经表示每秒传输 $1600\text{M}$ 次。$64\text{bit}=8\text{B}$，带宽为 $1600\text{M}\times8\text{B}/s=12800\text{MB/s}$，约为 $12.8\text{GB/s}$。

### 多通道与全双工

!!! question "例题 8：多通道存储器带宽"
    某计算机采用 $4$ 个相互独立的存储器通道，每个通道数据传送率为 $1600\,\mathrm{MT/s}$，有效数据宽度为 $64\text{bit}$。忽略额外开销，总带宽约为多少？

    A. $12.8\text{GB/s}$  
    B. $25.6\text{GB/s}$  
    C. $51.2\text{GB/s}$  
    D. $102.4\text{GB/s}$

    ??? success "参考答案"
        选 C。单通道一次传 $8\text{B}$，带宽为 $1600\text{M}\times8\text{B}/s=12.8\text{GB/s}$。四通道总带宽为 $4\times12.8=51.2\text{GB/s}$。

!!! question "例题 9：全双工链路"
    某点对点全双工链路的控制器用户接口，单方向每拍交付 $16\text{bit}$ 有效数据，每个用户时钟周期交付 $2$ 拍，时钟频率为 $2\text{GHz}$。若题目要求收发两个方向合计的有效带宽，应选多少？

    A. $4\text{GB/s}$  
    B. $8\text{GB/s}$  
    C. $16\text{GB/s}$  
    D. $32\text{GB/s}$

    ??? success "参考答案"
        选 C。单方向每次传 $16\text{bit}=2\text{B}$，每秒传输 $2\text{GHz}\times2$ 次，单方向带宽为 $8\text{GB/s}$。全双工合计两个方向，为 $16\text{GB/s}$。

### 理论带宽与事务有效速率

!!! question "例题 10：峰值参数中的干扰信息"
    某存储器总线宽度为 $64\text{bit}$，时钟频率为 $500\text{MHz}$，每个时钟周期传送 $2$ 次数据。题干还说明一次读事务第 $1$ 个周期传地址，第 $3$ 至第 $6$ 个周期传数据。若只问数据阶段可达到的峰值带宽，应选多少？

    A. $4\text{GB/s}$  
    B. $8\text{GB/s}$  
    C. $16\text{GB/s}$  
    D. $32\text{GB/s}$

    ??? success "参考答案"
        选 B。最大数据传输率按峰值参数算：$64\text{bit}=8\text{B}$，每秒传输次数为 $500\text{MHz}\times2$，带宽为 $8\text{B}\times1000\text{M}/s=8\text{GB/s}$。事务阶段用于分析具体访问耗时。

!!! question "例题 11：非突发读块时间"
    某存储器总线宽度为 $64\text{bit}$，时钟频率为 $1\text{GHz}$。在总线上传输一个地址或一个数据都占 $1$ 个时钟周期，主存准备一个 $64\text{bit}$ 数据需要 $5\text{ns}$，该总线不支持突发传输，事务不重叠，主存准备时间从地址阶段结束后起算。读取一个 $32\text{B}$ 块至少需要多久？

    A. $7\text{ns}$  
    B. $14\text{ns}$  
    C. $28\text{ns}$  
    D. $32\text{ns}$

    ??? success "参考答案"
        选 C。每次传 $64\text{bit}=8\text{B}$，读取 $32\text{B}$ 需要 $4$ 次。每次用时 $1\text{ns}+5\text{ns}+1\text{ns}=7\text{ns}$，总时间为 $4\times7\text{ns}=28\text{ns}$。

!!! question "例题 12：读写平均速率"
    某总线传输一个 $24\text{B}$ 块。读操作用 $8$ 个时钟周期，写操作用 $6$ 个时钟周期，时钟频率为 $120\text{MHz}$。若访问时间中 $75\%$ 为读、$25\%$ 为写，平均传输速率是多少？

    A. $360\text{MB/s}$  
    B. $390\text{MB/s}$  
    C. $405\text{MB/s}$  
    D. $420\text{MB/s}$

    ??? success "参考答案"
        选 B。读速率为 $24\text{B}\times120\text{MHz}/8=360\text{MB/s}$，写速率为 $24\text{B}\times120\text{MHz}/6=480\text{MB/s}$。按访问时间比例加权，平均速率为 $360\times75\%+480\times25\%=390\text{MB/s}$。

### 定时方式

!!! question "例题 13：同步定时"
    下列关于同步总线的说法，正确的是哪一项？

    A. 所有操作由统一时钟协调  
    B. 每次总线事务只能占用一个时钟周期  
    C. 所有设备都可以各自提供同步时钟  
    D. 同步方式主要靠请求/回答信号安排传输时间

    ??? success "参考答案"
        选 A。同步定时的基础是统一时钟。一次事务可由多个时钟周期组成；请求/回答握手属于异步定时的典型机制。

!!! question "例题 14：半同步与分离式"
    某总线事务中，主设备取得总线后只发送地址和命令，随后释放总线；从设备准备好数据后再申请总线，把数据送回主设备。这种安排的主要目的是什么？

    A. 减少等待期间的总线空占  
    B. 减少地址线数量  
    C. 让所有设备同时发送数据  
    D. 取消总线仲裁

    ??? success "参考答案"
        选 A。分离式定时把请求阶段和应答阶段分开，从设备准备数据期间总线可服务其他事务。

### 串行字符帧

!!! question "例题 15：异步串行字符帧"
    某异步串行设备每秒发送 $600$ 个字符。每个字符包含 $7$ 位数据、$1$ 位奇校验位，另有 $1$ 位起始位和 $1$ 位停止位。线路每秒至少传输多少比特？

    A. $4200\text{bit/s}$  
    B. $4800\text{bit/s}$  
    C. $5400\text{bit/s}$  
    D. $6000\text{bit/s}$

    ??? success "参考答案"
        选 D。每个字符帧共有 $1+7+1+1=10$ 位，每秒 $600$ 个字符，需要 $600\times10=6000\text{bit/s}$。

### 突发传输与非突发传输

突发传输用一个起始地址组织连续数据。比较耗时时还应写明后续数据是否继续等待，以及不同事务之间能否重叠。

!!! question "例题 16：突发传输的判断"
    某总线事务中，主设备先给出一个首地址，随后从设备连续返回 $8$ 个地址相邻的数据字，期间主设备没有逐个给出完整地址。该事务属于哪类传输？

    A. 串行传输  
    B. 突发传输  
    C. 异步传输  
    D. 分离式传输

    ??? success "参考答案"
        选 B。一次给出首地址后连续传送多个地址相邻的数据，是突发传输的典型特征。

!!! question "例题 17：突发与逐字传送的耗时差"
    沿用第 11 题的 $64$ 位、$1\,\mathrm{GHz}$ 总线，每次地址阶段 $1\,\mathrm{ns}$、首字准备 $5\,\mathrm{ns}$、每字数据阶段 $1\,\mathrm{ns}$。改为支持一次传 $4$ 字的突发，后续字无额外等待，求读取 $32\,\mathrm{B}$ 的耗时与有效速率。

    ??? success "参考答案"
        $T=1+5+4\times1=10\,\mathrm{ns}$，有效速率 $32\,\mathrm{B}/10\,\mathrm{ns}=3.2\,\mathrm{GB/s}$。非突发的 $28\,\mathrm{ns}$ 降到 $10\,\mathrm{ns}$，改善来自地址和准备开销的摊薄，物理数据阶段的峰值仍为 $8\,\mathrm{GB/s}$。

### 同步定时

同步定时依靠统一时钟。一次总线事务可能占用多个时钟周期，不等于一个事务只占一个周期。

!!! question "例题 18：同步事务中的等待周期"
    同步总线时钟为 $100\,\mathrm{MHz}$。一次事务占一个地址周期、两个等待周期和四个数据周期，每个数据周期传 $8\,\mathrm{B}$。事务有效速率是多少？

    ??? success "参考答案"
        时钟周期为 $10\,\mathrm{ns}$，事务耗时 $7\times10=70\,\mathrm{ns}$，有效数据为 $32\,\mathrm{B}$。有效速率为 $32/70\,\mathrm{B/ns}\approx457.1\,\mathrm{MB/s}$，低于数据阶段的峰值 $800\,\mathrm{MB/s}$。统一时钟允许事务跨多周期。

### 异步定时与互锁

异步定时不依赖双方共享的统一时钟，靠请求和回答信号配合。各端内部仍可有自己的时钟；跨时钟域还需处理亚稳态，握手协议不能省掉电路同步要求。

!!! question "例题 19：异步通信方式"
    某 I/O 接口与打印机交换信息，两者速度差异较大，系统希望按设备实际准备情况完成传输。较适合采用哪种定时方式？

    A. 同步定时  
    B. 异步定时  
    C. 固定周期突发传输  
    D. 只用地址线控制

    ??? success "参考答案"
        选 B。异步定时通过请求/回答信号协调传输，适合速度差异较大的设备。

!!! question "例题 20：互锁方式速度比较"
    在器件与传播条件相同、预定时限均满足要求的教学比较中，哪种异步互锁方式的附加握手等待通常最少？

    A. 不互锁  
    B. 半互锁  
    C. 全互锁  
    D. 三者相同

    ??? success "参考答案"
        选 A。在其他条件相同的教学比较中，不互锁撤销信号不等待对方确认，附加等待少。它依赖预定时间满足设备约束，不能据此保证任意设备组合下既最快又可靠。

### 半同步与分离式定时

半同步定时在统一时钟下加入 `Wait` 信号。分离式定时把请求和应答拆开，中间释放总线，提高等待期间的总线利用率。

!!! question "例题 21：半同步定时"
    某同步总线连接了速度较慢的 I/O 接口。系统保留统一时钟，同时增加一条 `Wait` 信号线；慢设备未准备好时，主设备插入等待周期。该方式属于哪一种？

    A. 同步定时  
    B. 异步定时  
    C. 半同步定时  
    D. 分离式定时

    ??? success "参考答案"
        选 C。半同步定时仍按统一时钟工作，同时通过 `Wait` 信号适配慢设备。

!!! question "例题 22：分离事务的请求匹配"
    一个主设备连续发出读请求 $A$ 和 $B$，地址阶段后都释放总线。$B$ 的数据先准备好，协议允许先返回 $B$。除了地址和数据本身，还需要什么机制使主设备正确识别响应？分离事务是否必然允许乱序返回？

    ??? success "参考答案"
        需要事务标识或其他足以匹配未完成请求的上下文，让响应与对应请求关联。分离事务只要求请求与应答分时占用资源；是否允许乱序完成由协议另行规定，也可以要求按序应答。

### 串行帧效率与链路选择

物理线路速率与用户有效数据率之间还隔着成帧、编码和协议开销。异步字符帧只是其中一种模型，高速串行链路不必使用 UART 式起始位和停止位。

!!! question "例题 23：串行帧的有效载荷效率"
    某二进制串行链路速率为 $115200\,\mathrm{bit/s}$，每字符含一位起始、八位数据、无校验、一位停止。忽略字符间空闲，求每秒最大字符数和有效数据字节率。

    ??? success "参考答案"
        一帧 $10$ 位，每字符携带一个字节，故为 $115200/10=11520$ 字符/s，即 $11520\,\mathrm{B/s}$。有效位比例为 $8/10=80\%$；线路比特率不能直接除以八当作有效字节率。

!!! question "例题 24：串行和并行"
    下列关于串行和并行传输的说法，较合适的是哪一项？

    A. 并行线多，所以现代高速接口都优先采用并行总线  
    B. 串行传输线路少，现代高速接口可通过提高频率和多通道获得高带宽  
    C. `USB` 可以在同一条数据线上同时传输多个并行位  
    D. `PCIe` 的 `x16` 表示一次并行传输 $16\text{bit}$

    ??? success "参考答案"
        选 B。现代高速接口常用串行链路，原因包括线路少、布线和信号完整性更容易控制。`PCIe x16` 表示 $16$ 条通道组合。

### 块传输与平均速率

综合题经常把一个块分成多个字，再给出地址周期、等待周期、数据周期。读写耗时不同时，还会按读写比例计算平均速率。

!!! question "例题 25：块传输速率"
    某 $64\text{bit}$ 总线时钟频率为 $70\text{MHz}$，一个数据块由 $5$ 个 $64\text{bit}$ 字组成，传输一个块占 $7$ 个时钟周期。该块传输速率约为多少？

    A. $200\text{MB/s}$  
    B. $300\text{MB/s}$  
    C. $400\text{MB/s}$  
    D. $500\text{MB/s}$

    ??? success "参考答案"
        选 C。一个块的数据量为 $5\times64\text{bit}=40\text{B}$，传输一个块的频率为 $70\text{MHz}/7=10\text{MHz}$，速率为 $40\text{B}\times10\text{MHz}=400\text{MB/s}$。

!!! question "例题 26：按请求数量加权的读写速率"
    同样是每块 $24\,\mathrm{B}$、读耗时八拍、写耗时六拍、时钟 $120\,\mathrm{MHz}$，若这次规定请求数量中 $75\%$ 是读、$25\%$ 是写，且事务串行，平均速率是多少？

    ??? success "参考答案"
        每请求的平均周期为 $0.75\times8+0.25\times6=7.5$，速率为

        $$
        \frac{24\,\mathrm{B}\times120\times10^6\,\mathrm{s^{-1}}}{7.5}
        =384\,\mathrm{MB/s}
        $$

        第 12 题按时间占比对速率加权，得到 $390\,\mathrm{MB/s}$；这里按请求数量对耗时加权，不能沿用同一加权式。

## 解题检查

- 数据总线能传指令、操作数、状态字、中断类型号；握手、确认、读写命令走控制总线。
- 地址线位数决定寻址能力，数据线位数决定一次并行传输的数据宽度。
- 地址/数据线复用节省引脚，不直接提高传输速率。
- 突发传输提高连续块传输效率，因为它减少重复地址开销和等待开销。
- 数据阶段峰值看物理参数；协议可持续吞吐和块读取时间要按事务阶段、等待与重叠条件算。
- 同步总线的时钟频率不一定等于工作频率，也不表示一个事务只占一个时钟周期。
- 异步总线一次握手完成一次通信过程，通常交换多位数据。
- PCIe 是高速串行点对点连接，`PCIe x16` 表示 $16$ 条串行通道。
- USB 是串行总线，支持即插即用、热插拔和多设备连接。

## PCIe、并发请求与一致性边界

PCIe 每条 lane 有独立的收发方向，通过多条 lane 组合提高带宽。事务经数据包传送，交换机可让不同链路并发；仍可能在同一上行链路、设备队列或内存通道发生争用。“系统一次只能有一个设备发送”只适用于明确的共享线路范围。

链路协商的速率和宽度共同决定上限，插槽外形为 `x16` 不保证电气连接和当前协商状态都是 `x16`。对采用二进制信号及 $128/130$ 编码的 PCIe 3.0–5.0，单向编码后带宽可写成：

$$
B_{\mathrm{link}}=\frac{r\times10^9\times l}{8}\times\frac{128}{130}\;\mathrm{B/s}
$$

其中 $r$ 为每 lane 的 $\mathrm{GT/s}$ 数值，$l$ 为 lane 数。这个结果仍未扣除包头、校验、流控和重传；PCIe 后续代际采用不同信号与编码机制，不能继续机械套用 $128/130$。

!!! question "例题 27：PCIe 编码与有效负载"
    某 PCIe 4.0 链路协商为 `x4`，每 lane 为 $16\,\mathrm{GT/s}$，采用 $128/130$ 编码。求单向编码后理论带宽；若给定场景中用户负载占编码后可用字节的 $90\%$，有效带宽约为多少？

    ??? success "参考答案"
        单向带宽为 $16\times10^9\times4\times128/(130\times8)\approx7.877\,\mathrm{GB/s}$；按题给效率约为 $7.089\,\mathrm{GB/s}$。$90\%$ 是特定负载假设，不能当作 PCIe 固定效率；全双工合计才再乘二。

PCIe 通信和 CPU Cache 一致性是不同层。设备 DMA 是否与 CPU 缓存自动协调由平台保证；即使数据一致，也仍要遵循设备访问顺序和内存屏障。另一方面，CPU 对设备 MMIO 寄存器的写入可能是 posted write，软件完成写指令不一定意味着设备已经执行其作用，必要时应按驱动 API 和设备规范确认完成。

[Linux PCI 驱动文档](https://docs.kernel.org/PCI/pci.html)说明 PCI 设备资源和 DMA 使用；[Linux PCI 核心实现](https://github.com/torvalds/linux/blob/master/drivers/pci/pci.h)中的 `PCIE_SPEED2MBS_ENC` 可核对速率与编码因素；[DMA 映射指南](https://docs.kernel.org/core-api/dma-api-howto.html)说明一致性与顺序约束，[设备 I/O 文档](https://docs.kernel.org/driver-api/device-io.html)说明 posted write 和访问完成。CPU 内部单总线题见[CPU 内部主要元件](cpu-components-overview.md)，多通道与交叉访存见[主存储器](main-memory.md)。
