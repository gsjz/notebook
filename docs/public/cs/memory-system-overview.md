# 存储器概述

存储系统以不同介质和管理机制协调速度、容量、成本与持久性。寄存器、Cache、主存、辅存构成常见层次，但各层的接口不同：指令显式使用寄存器，普通加载/存储经过缓存与地址转换，磁盘和 SSD 则通常通过操作系统与 I/O 控制器访问。

$$
\text{寄存器}\;\longleftrightarrow\;\text{Cache}\;\longleftrightarrow\;\text{主存}\;\longleftrightarrow\;\text{辅存}
$$

这幅层次图适合说明常见的数据流向，不能理解成每次访问都依次搜索所有层，也不能推出上层和下层始终保存完全相同的内容。

## 分类标准与器件属性

对存储器分类时，先明确分类维度。同一个 DRAM 可以同时属于半导体、随机存取、可读写、易失性和破坏性读出存储器。

| 分类维度 | 主要类别与例子 | 判断依据 |
| --- | --- | --- |
| 介质 | 半导体：SRAM、DRAM、Flash；磁性介质：硬盘、磁带；光介质：光盘 | 用何种物理状态保存信息 |
| 访问方式 | 随机、顺序、直接、相联 | 怎样定位所需信息 |
| 可更改性 | 可读写、只读及可编程 ROM 系列 | 正常操作与特殊编程时能否改写 |
| 断电保持性 | 易失、非易失 | 断电后是否保持信息 |
| 读出破坏性 | 破坏性、非破坏性 | 读出后是否需要恢复原内容 |

### 随机、顺序、直接和相联访问

随机存取允许按地址选择任意单元，教学模型中存取时间与地址位置无关。SRAM、DRAM 均属于这一类；现代 DRAM 的行命中、bank 冲突和排队仍会影响实际延迟，随机存取不保证所有请求具有完全相同的实测时间。

顺序存取需要经过前面的记录或介质位置，磁带是典型实例。直接存取先定位到一个区域，再等待区域内的目标位置，机械磁盘的寻道与旋转符合这一模型。“直接”描述定位方式，与 CPU 是否能用普通加载指令访问介质无关。

相联存取按内容或键匹配，例如 TLB 中用虚拟页号匹配地址转换条目、Cache 中比较标签。实际 TLB 可以组相联，Cache 数据阵列也不必全部由内容寻址存储器构成；相联查找描述其中的匹配机制。

!!! question "例题：相联查找的判定"
    某部件输入虚拟页号，比较一组条目的标签，命中后返回物理页号和访问权限。这体现了哪种访问机制？它返回的是程序数据吗？

    ??? success "参考答案"
        标签匹配体现相联查找。返回的是地址转换及权限信息，随后还需根据转换结果访问数据；TLB 命中不能代替数据 Cache 命中。

### RAM、ROM 与保存性

RAM 通常指工作时可随机读写的存储器，常见 SRAM、DRAM 均易失；ROM 家族强调非易失与主要读出用途，掩模 ROM、PROM、EPROM、EEPROM 的编程条件不同。ROM 也可以按地址随机读出，不能把“随机存取”和“可读写”当成同一个分类标准。

Flash 支持电擦除和重写，常在教材中归入 ROM 技术谱系。这个分类不表示 SSD、U 盘在使用上只读。非易失性也不等于永久可靠：保持时间、擦写寿命及掉电时尚未落盘的数据仍须分别考虑。

DRAM 的刷新由电荷泄漏引起，读后再生由读出扰动原状态引起；两者都涉及恢复电荷，但触发原因不同。

## 地址、存储单元与数据传送

存储元保存一位；编址单位是一个地址所代表的数据量；存储芯片的组织、处理器机器字长和一次总线传输宽度可以不同。计算容量前必须确定题目中的“字”指哪一层。

若有 $N$ 个可编址单元，每个单元为 $u$ 字节：

$$
C=Nu\,\mathrm{B},\qquad a=\lceil\log_2N\rceil
$$

$a$ 位地址最多表示 $2^a$ 个位置。字节编址时 $u=1$；若每个地址对应一个 $w$ 位字，则容量为 $2^a w$ 位。地址加一表示移动一个编址单位，与数据总线宽度无关。

教学主存接口包含存储阵列、地址译码器、数据 I/O 电路和控制电路。读操作先提供地址和读命令，再把响应数据送入 MDR；写操作提供地址、数据和写命令。MAR 暂存地址，MDR 暂存数据，因此在该接口模型中二者位宽分别对应地址宽度和传送宽度。

!!! question "例题：MAR、MDR 与容量"
    某字节编址机器的地址线为 $36$ 位，数据线为 $64$ 位。求最大可寻址容量与一次并行传送量。若改为每字 $32$ 位的字编址，保持地址位数不变，容量如何变化？

    ??? success "参考答案"
        字节编址容量为 $2^{36}\,\mathrm{B}=64\,\mathrm{GiB}$，一次传送 $64/8=8\,\mathrm{B}$，对应 MAR 为 $36$ 位、MDR 为 $64$ 位。

        字编址容量为 $2^{36}\times4\,\mathrm{B}=256\,\mathrm{GiB}$。改变编址单位扩大了每个地址代表的数据量，没有增加地址个数，也没有据此改变总线一次传送量。

处理器能表示的地址范围、操作系统映射的虚拟地址范围、实际安装的物理内存容量，应在实际系统中分别核对。

## 局部性与层次管理

时间局部性指近期使用的信息可能再次使用；空间局部性指相邻地址可能很快被使用。循环中的标量具有时间局部性，顺序遍历数组具有空间局部性。缓存以块为单位调入，让有限高速容量覆盖一部分热点访问。

| 层次 | 主要目的 | 搬运单位与管理者 |
| --- | --- | --- |
| Cache—主存 | 降低平均访问延迟、减少下层流量 | 缓存行，主要由硬件管理 |
| 主存—辅存 | 组织文件缓存、按需调页和持久化 | 页或 I/O 块，操作系统与硬件协作 |
| TLB—页表 | 加速地址转换 | 地址转换条目，填充方式由体系结构决定 |

Cache 管理通常不要求应用显式搬运数据，但性能、缓存维护与并发行为仍可观察。虚拟内存提供地址空间、隔离、权限和按需分配，即使系统没有交换区，它仍然成立；“地址空间大于主存”是可能的效果，不是其唯一目的。

### 缓存未命中与缺页

一次数据 Cache 未命中通常继续向下级缓存或主存请求一条缓存行，不自动触发磁盘读取。TLB 未命中先寻找页表转换；只有页表表明目标页未驻留、需要操作系统处理时，才可能发生缺页异常。缺页也可能只需分配清零页或进行写时复制，未必存在磁盘读操作。

写回 Cache 可以持有尚未同步到主存的脏数据；主存中的匿名页也不一定有辅存副本。多级 Cache 还可以采用包含、排他或非包含关系。因此“上一层是下一层的子集副本”只能作为入门的数据来源直觉，不能用于证明内容实时一致。

## 延迟、周期与带宽

存取时间 $T_a$ 表示一次操作从请求有效到结果有效的延迟。存储周期 $T_m$ 表示同一存储体连续启动独立访问的最小间隔。在非流水单体模型中，恢复操作常使 $T_m\ge T_a$；多 bank 或流水化接口的全局启动间隔可小于单次访问延迟。

每个存储周期传送 $q$ 字节时，单体理论带宽为：

$$
B=\frac{q}{T_m}
$$

带宽反映单位时间完成的数据量，延迟反映一个请求等待多久。多通道和并发请求可以提高吞吐，不一定按比例缩短单次随机加载的延迟。

!!! question "例题：传输率与单位"
    某非流水存储器存储周期为 $250\,\mathrm{ns}$，每次读出 $16$ 位。忽略控制开销，理论数据传输率是多少？

    ??? success "参考答案"
        每次 $2\,\mathrm{B}$，所以

        $$
        B=\frac{2}{250\times10^{-9}}\,\mathrm{B/s}
        =8\times10^6\,\mathrm{B/s}=8\,\mathrm{MB/s}
        $$

        换算成二进制单位约为 $7.63\,\mathrm{MiB/s}$。$\mathrm{MB}=10^6\,\mathrm{B}$，$\mathrm{MiB}=2^{20}\,\mathrm{B}$；只有题目明确沿用其他约定时才另作换算。

### 平均访问时间

对阻塞式单级 Cache，设每次查找耗时 $t_c$，未命中概率为 $m$，未命中后**额外**开销为 $P$，则：

$$
AMAT=t_c+mP
$$

若题目给的是未命中访问的**总耗时** $t_{\mathrm{miss}}$，应写为 $(1-m)t_c+mt_{\mathrm{miss}}$，不能再重复加入查找时间。多级模型还需确认命中率是局部命中率还是全局命中率。

!!! question "例题：L1、L2 与主存"
    L1 查找耗时 $1\,\mathrm{ns}$，未命中率 $5\%$；L2 对收到的请求查找耗时 $5\,\mathrm{ns}$，局部未命中率 $20\%$；L2 未命中后额外主存代价为 $80\,\mathrm{ns}$。不考虑重叠，求 AMAT。

    ??? success "参考答案"
        $$
        AMAT=1+0.05(5+0.20\times80)=2.05\,\mathrm{ns}
        $$

        到达主存的比例为 $0.05\times0.20=1\%$。L2 的 $20\%$ 是到达 L2 的请求中的比例，不能直接当成全部访问的比例。

这个模型适合基础计算。乱序执行、预取、多条未完成请求和内存级并行会使部分等待重叠，程序实际停顿时间不能总用 AMAT 乘访问次数得到。

## 多核系统中的容量与位置

NUMA 系统把内存分布到不同节点，处理器访问本地节点与远端节点的代价可能不同。程序拥有足够总内存，并不保证数据位于合适节点。操作系统的内存分配策略、线程放置和首次触页位置会影响实际带宽与延迟；Linux 的默认本地分配策略还受策略设置和内存压力影响。

多核 Cache 一致性解决同一内存位置的副本如何协调；内存一致性模型规定多个位置的读写在观察上允许怎样排序。前者不自动替代后者，程序同步仍需遵循语言与 ISA 的原子操作和屏障规则。

[Linux NUMA 内存策略文档](https://docs.kernel.org/admin-guide/mm/numa_memory_policy.html)说明节点选择与分配策略；[Linux DMA 映射指南](https://docs.kernel.org/core-api/dma-api-howto.html)展示设备访问地址和缓存一致性如何影响内存管理。芯片级组织见[主存储器](main-memory.md)，持久化与块设备见[外部存储器](external-storage.md)。
