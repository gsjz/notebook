# 汇编语言基础

!!! abstract "本文要点"
    本文先建立读汇编所需的最小模型：寄存器、内存、指令、标志位与控制流；再用一个简单例子把这些概念串起来；最后按 408 / 计组常见考法补充应试知识。

## 什么是汇编语言

汇编语言可以看作 **机器指令的可读文本形式**。CPU 真正执行的是机器码，而汇编语言只是把这些二进制指令写成人更容易阅读和修改的样子。

同一段高级语言代码，在不同指令集体系结构（ISA）上，可能会被翻译成完全不同的汇编代码。因此，汇编语言天然依赖具体架构，例如 x86、ARM、RISC-V 都有各自的寄存器、指令和调用约定。

!!! note "先抓住本质"
    学汇编时，最重要的不是死记某几条指令，而是理解“CPU 如何取指、取数、运算、改标志位、改变下一条指令地址”这一整套执行模型。

## 先建立一个最小执行模型

### 寄存器

寄存器是 CPU 内部速度最快的一组存储单元。读汇编时，最常见的几类寄存器包括：

- 通用寄存器：暂存操作数、中间结果或地址。
- `PC`：程序计数器，保存下一条将要执行的指令地址。
- `SP`：栈指针，指向当前栈顶。
- 标志寄存器：保存最近一次运算产生的状态，例如零标志、进位标志、溢出标志、符号标志。

很多汇编题的核心，不是“某条指令会不会写内存”，而是“它改了哪个寄存器、是否改了标志位、下一条会跳到哪里”。

### 内存与地址

内存可以理解为一个按地址编号的大数组。程序中的指令和数据通常都放在内存里，CPU 通过地址访问它们。

- 读内存：把某个地址处的数据取到寄存器。
- 写内存：把寄存器里的数据写回某个地址。
- 访问效率：通常寄存器最快，内存更慢。

很多体系结构按字节编址，因此地址通常表示“第几个字节”。而一个整数往往要占多个字节，所以还会涉及大端/小端存放方式。

!!! tip "读汇编先找四样"
    先标出当前用到的寄存器、哪些指令会改标志位、哪些语句会改 `PC`、栈是否在变化。这样通常就能先读懂七八成。

### 指令、操作数与执行结果

一条指令通常至少包含两部分：

- 操作码：要做什么，例如加、减、跳转、调用。
- 操作数信息：对谁做、结果放哪。

例如：

```asm
mov eax, ebx
add eax, 4
```

可以粗略理解为：

- 第一条把 `ebx` 的值复制到 `eax`。
- 第二条把 `eax` 与立即数 `4` 相加，结果仍放回 `eax`。

## 常见指令类别

### 数据传送

最常见的是“寄存器和寄存器之间”“内存和寄存器之间”“立即数和寄存器之间”的数据移动。

```asm title="data-move.asm"
mov eax, 42
mov ebx, eax
mov ecx, [rbp-4]
mov [rbp-8], eax
```

上面四条语句分别表示：

- 立即数送入寄存器。
- 寄存器到寄存器。
- 从内存读到寄存器。
- 从寄存器写回内存。

### 算术与逻辑运算

常见运算包括：

- `add` / `sub`：加减。
- `inc` / `dec`：加 1、减 1。
- `and` / `or` / `xor` / `not`：逻辑运算。
- `shl` / `shr`：移位。

这些指令除了改写结果寄存器，通常还会顺带更新标志位。后续条件跳转常常依赖这些标志位。

### 比较、跳转与循环

汇编里没有“高级语言的 if / while 关键字”，它们最终都要落到“比较 + 修改 `PC`”。

常见模式如下：

```asm
cmp eax, ebx
je  equal_label
jg  greater_label
jmp done
```

可以把它理解为：

- `cmp` 先做一次比较，本质上会设置标志位。
- `je`、`jg` 这类条件转移指令根据标志位决定是否跳转。
- `jmp` 是无条件跳转。

循环也只是“比较 + 条件跳转”的重复。

### 调用、返回与栈

函数调用在汇编层通常表现为：

- `call`：跳到被调过程，同时保存返回地址。
- `ret`：取回返回地址，跳回调用点后面。

很多体系结构会把返回地址放到栈里，也有体系结构会放在专门的链接寄存器里。无论具体实现如何，`call` 和普通 `jmp` 的关键区别始终是：**调用需要能回来，转移不需要**。

!!! warning "一个常见误区"
    `call` 不是“更高级的 jmp”，它比 `jmp` 多了“保存返回位置”这件事。

## 常见寻址方式

读汇编题时，很多错误都不是出在指令本身，而是把“地址”和“地址里的内容”混淆了。

### 立即寻址

操作数直接写在指令里。

```asm
mov eax, 5
```

这里的 `5` 不是某个地址，而是操作数本身。

### 寄存器寻址

操作数存放在寄存器中。

```asm
mov eax, ebx
```

### 直接寻址

指令里给出的就是操作数所在地址，形式上可记为：

$$
EA = A
$$

### 间接寻址

指令里给出的地址不是操作数地址，而是“保存了有效地址的那个单元地址”，即：

$$
EA = (A)
$$

### 寄存器间接寻址

寄存器中保存操作数地址：

$$
EA = (R_i)
$$

例如：

```asm
mov eax, [rbx]
```

### 相对寻址

常用于转移指令，目标地址由当前 `PC` 与偏移量相加得到：

$$
EA = (PC) + A
$$

它的好处是程序位置变化后，跳转仍然可以成立，因此很适合实现相对跳转和可重定位代码。

### 基址寻址

由基址寄存器和偏移量共同形成地址：

$$
EA = (BR) + A
$$

它更偏“系统视角”，常用于支持程序重定位、存储分配等。

### 变址寻址

由变址寄存器和形式地址共同形成地址：

$$
EA = (IX) + A
$$

它更偏“用户视角”，很适合处理数组、表和循环访问。

### 堆栈寻址

操作数位置由 `SP` 隐含给出，常见于 `push`、`pop`、`call`、`ret` 等指令。

!!! warning "最容易混淆的两组概念"
    立即寻址里，指令字段装的是“值”；直接寻址里，指令字段装的是“地址”。

    基址寻址强调“基地址相对稳定、偏移量由指令给出”；变址寻址强调“基址相对固定、变址寄存器随访问过程动态变化”。

## 读一个简单例子

!!! note "示例约定"
    下面示例采用 x86-64 的 Intel 风格语法，只借它展示常见概念。不同架构的寄存器名字和调用约定会不同，但分析方法是共通的。

下面这段代码计算 $1+2+\cdots+n$：

```asm title="sum_to_n.asm"
mov eax, 0
mov ecx, 1
.Lloop:
cmp ecx, edi
jg .Ldone
add eax, ecx
inc ecx
jmp .Lloop
.Ldone:
ret
```

可以这样读：

1. `eax` 用来存放当前累加和，初值为 `0`。
2. `ecx` 充当循环变量，初值为 `1`。
3. `cmp ecx, edi` 比较当前 `i` 和 `n`，并设置标志位。
4. `jg .Ldone` 表示若 `i > n`，则退出循环。
5. `add eax, ecx` 把当前 `i` 累加到结果里。
6. `inc ecx` 让 `i` 自增。
7. `jmp .Lloop` 回到循环开头。
8. `ret` 返回结果。

如果把它翻译成接近高级语言的伪代码，大致就是：

```c
int sum_to_n(int n) {
    int sum = 0;
    int i = 1;
    while (i <= n) {
        sum += i;
        i++;
    }
    return sum;
}
```

!!! tip "做机器级代码题的实用顺序"
    先找循环变量和结果寄存器，再找谁负责比较、谁负责跳转，最后再还原成伪代码。不要一上来逐词翻译每条指令。

## 408 / 应试补充

### ISA 到底规定什么

从计组视角看，ISA 主要规定的是程序员可见的机器级接口，例如：

- 指令格式和指令类型。
- 寻址方式。
- 可访问寄存器的个数、编号和位数。
- 数据类型及大端/小端存放方式。
- 条件码、异常/中断相关的可见语义。

而像“是否采用微程序控制器”“是否采用单总线数据通路”“ALU 的具体电路实现”这类内容，属于微架构实现细节，不属于 ISA 本身。

### 常考寄存器区分

- `PC`：保存下一条将执行的指令地址；顺序执行时自动递增，转移时被改写。
- `IR`：保存当前正在执行的指令。
- `MAR`：保存当前要访问的主存地址。
- `MDR`：保存从主存读出的数据或将写回主存的数据。
- `FR / PSW`：保存运算后的状态信息，条件转移常依据它判断。

!!! note "速记"
    `PC` 管“下一条”，`IR` 管“当前这条”，`MAR` 放地址，`MDR` 放数据，`FR` 看状态。

### 用户可见与不可见寄存器

从汇编程序员能否直接访问的角度，可粗略分成两类：

- 用户可见：通用寄存器、基址寄存器、变址寄存器、堆栈指针、程序计数器等。
- 用户不可见：`IR`、`MAR`、`MDR` 等。

考试里经常把这组概念和“谁能被程序直接读写”放在一起考。

### 常见寻址方式速记公式

- 立即寻址：操作数就是 `A`
- 直接寻址：$EA=A$
- 间接寻址：$EA=(A)$
- 寄存器寻址：操作数在 `R_i`
- 寄存器间接寻址：$EA=(R_i)$
- 相对寻址：$EA=(PC)+A$
- 基址寻址：$EA=(BR)+A$
- 变址寻址：$EA=(IX)+A$
- 堆栈寻址：由 `SP` 隐含给出

### 易混点速记

- 条件转移看的不是“寄存器名字”，而是此前指令设置的标志位。
- `call` 会保留返回位置，`jmp` 不会。
- 相对寻址常用于转移，基址寻址偏系统重定位，变址寻址偏数组和循环。
- `PC` 自增多少，取决于编址方式和指令长度，不一定永远是 `+1`。

!!! success "建议学习顺序"
    先掌握寄存器、标志位和控制流，再掌握寻址方式，最后去读循环、分支和函数调用对应的机器级代码。这样学习成本最低，也最接近考试出题方式。
